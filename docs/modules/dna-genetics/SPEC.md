# DNA / Genetics Module — SPEC
_Status: PLANNED (Immersion Audit Updated)_

## 1. Learning Objectives (Tier-Adapted)
- **Foundation:** Understand that DNA is a double helix carrying genetic instructions; complementary base pairing ($A=T, G\equiv C$); genes code for proteins via RNA; mutations alter recipes; CRISPR is a molecular tool that can edit DNA typos.
- **Advanced:** Explain DNA replication mechanisms (helicase, DNA polymerase III, leading/lagging strands, Okazaki fragments); trace transcription (RNA polymerase) and translation (ribosome A/P/E sites, tRNA, codons); analyze mutation classes (missense, nonsense, frameshift); detail CRISPR-Cas9 components (sgRNA, Cas9 endonuclease, PAM recognition motif 5'-NGG).
- **Expert:** Calculate DNA thermodynamic duplex stability ($\Delta G^\circ$, melting temperature $T_m$); evaluate non-homologous end joining (NHEJ) vs homology-directed repair (HDR) kinetics; analyze structural Cas9 domain movements (HNH and RuvC nuclease active sites) during R-loop formation.

## 3. Beat Timeline (15–20 minutes)
1. **0:00–2:00 (Beat 1 — Opening Hook):** Stand in a biological cell illuminated by bioluminescent organelles. Zoom down through nuclear pore into chromosome territory.
2. **2:00–5:00 (Beat 2 — Double Helix & Base Pairing):** Walk along the giant double helix. Inspect spatial anchors on base pairs ($A-T, G-C$).
3. **5:00–8:00 (Beat 3 — First Physical Challenge: Complementary Base Snapping):** Physically grab free nucleotide triphosphates and snap them onto exposed template bases.
4. **8:00–12:00 (Beat 4 — Replication Fork & Translation):** Pull the helix apart to operate helicase. Enter the ribosome to thread mRNA codons and build a peptide chain.
5. **12:00–16:00 (Beat 5 — Capstone Challenge: CRISPR Cas9 Gene Editing):** Manually inspect a mutated beta-globin gene causing Sickle Cell disease; align guide RNA, clamp Cas9 scissors, cut the mutated strand, and insert the corrective donor template.
6. **16:00–18:00 (Beat 6 — Genomics & Biodiversity):** Explore African human genetic diversity (Turkana Basin hominin origins) and crop genomics.
7. **18:00–20:00 (Beat 7 — Reflection & Exit Horizon):** Earn "Genomics Architect" badge. Review agricultural biotechnology applications in Kenya. Hub portal opens.
